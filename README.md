# BearyFun Gym prototype

Interactive HTML demonstrations of the proposed student and customer engagement platform.

[Open the prototype](https://chenxy128.github.io/bfg-demo/)

- Use Case 1: enquiries, trial recommendations and enrolment — Centre Head workspace.
- Use Case 2: student profiles, Coach feedback and Centre Head-approved progress reports — the same Centre Head workspace.
- Use Case 3: student payments, centre finances, demand trends and indicative forecasts — Finance Manager workspace.

All people, records, fees and financial figures are fictional examples. Messages, AI and payment services are simulated. Changes stay in the visitor’s browser; there is no shared backend.

## Hosting

GitHub Pages serves these static files from the root of the main branch. `.nojekyll` keeps the HTML files unchanged. No installation or build is needed.
